MCP setup

Wire Ezra into any MCP client.

The endpoint is https://ezramcp.com/v1/mcp. Auth header is Authorization: Bearer ezra_live_…. JSON-RPC 2.0 over HTTP.

The 7 tools

  • get_verses_by_topic(topic, limit?) — primary lookup, returns verses with refs and text
  • list_topics(category?, limit?) — discovery; filter by theme / story / parable
  • get_pericope(name) — return a story or parable with its verses
  • find_topic(query) — fuzzy search topic names
  • get_related_topics(topic, limit?) — topics that co-occur with this one
  • get_verse(ref) — single-verse lookup with topics and pericopes
  • get_chapter(book, chapter) — full chapter with per-verse topics

Example tool call

curl https://ezramcp.com/v1/mcp \
  -H "Authorization: Bearer ezra_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0", "id": 1, "method": "tools/call",
    "params": {
      "name": "get_verses_by_topic",
      "arguments": { "topic": "Forgiveness", "limit": 5 }
    }
  }'

Rate limits

  • Free — 20 tool calls per month per key
  • Pro — 10,000 per month
  • Max — 100,000 per month

Rate-limit errors return JSON-RPC code: -32004 with an upgrade_url. Counts reset at the start of each UTC month.
